# Tickets

Buildable work items, written by the **business-analyst** agent from requirements
that the **product-manager** agent has confirmed. Each ticket is one page or one
focused feature, with acceptance criteria the **builder** implements against and the
**reviewer** checks off.

Naming: `NNN-slug.md` (e.g. `001-site-header-footer.md`), zero-padded and
incrementing. One ticket per file. Keep them small and reviewable.
